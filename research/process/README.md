# Process Reviews

This directory stores durable reviews of the repository's own process.

Use it for substantial methodology changes, repeated research defects, missed-candidate postmortems, source-list upgrades, scoring changes, automation opportunities, validation gaps, dashboard workflow reviews, and cleanup rules that should survive across future agents.

Use [../../templates/meta-self-improvement.md](../../templates/meta-self-improvement.md) for process reviews.

Do not use this directory for scratch notes, raw downloads, temporary web captures, or local-only logs. Keep process notes concise, auditable, and tied to the satellite account mission.
